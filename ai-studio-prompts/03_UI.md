# Phase 4 Brief

Implement UI only through application use cases, never DAOs. Cover first run, projects, grants, indexing, project tabs, search/filter/trace, typed records, fact history/conflicts, prompts, plans/tasks, sessions/checkpoints/handoffs, proposals, context preview, audit, server settings, and backup navigation. Use immutable StateFlow state with loading, empty, error, retry, and cancellation. Test accessibility, dark theme, large text, Hebrew, RTL, and mixed identifiers. Use no fake data. Confirm privileged actions. Build, test, report, and stop.
